# Вклад в проект

Главный принцип — не смешивать сведения продавца, предположения и результаты измерений.

Для каждого нового утверждения указывайте один из статусов:

- подтверждено измерением;
- заявлено продавцом;
- выведено из схемы или наблюдения;
- предположение;
- не подтверждено.

При добавлении результатов испытаний указывайте ревизию платы, напряжение питания, измерительные приборы и исходные данные.
