# Безопасность

JZ-PWM2 не следует использовать как единственный элемент безопасного отключения силовой нагрузки.

Сообщения об опасном поведении — самопроизвольном запуске, неверных импульсах при включении, превышении уровней или перегреве — оформляйте отдельной issue с маркировкой платы и условиями воспроизведения.
