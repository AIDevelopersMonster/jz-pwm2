# Интеграция JZ-PWM2 в микроконтроллерную систему

## Рекомендуемая роль

Модуль следует использовать как заменяемый периферийный PWM-исполнитель:

```text
основной контроллер / ПК
        |
        | UART или шлюз
        v
     JZ-PWM2
        |
        | PWM1 / PWM2
        v
внешний драйвер или сигнальный вход нагрузки
```

Он подходит, когда PWM не является основной функцией системы и может формироваться автономно от главного процессора.

## Транспортная абстракция

Верхний уровень должен работать с унифицированными операциями:

```text
set_frequency(channel, frequency_hz)
set_duty(channel, duty_percent)
disable_output(channel)
```

Последняя операция не должна полагаться на недоказанное значение 0%. Ее следует реализовать аппаратным входом `ENABLE`, логическим элементом, буфером с разрешением или отключением драйвера нагрузки.

Внешний шлюз может преобразовывать команды из:

- USB;
- RS-485;
- CAN;
- I2C;
- Ethernet;
- Wi-Fi/MQTT;
- Bluetooth;

в локальный UART модуля.

## Состояние системы

Поскольку команды чтения параметров не документированы, главный контроллер должен хранить желаемое состояние сам и повторно записывать его при запуске.

Рекомендуемый цикл:

1. Перевести силовой драйвер в безопасное состояние.
2. Инициализировать UART.
3. Записать частоту обоих каналов.
4. Записать заполнение обоих каналов.
5. Проверить ответ на каждую команду.
6. При необходимости измерить фактический PWM входом захвата таймера.
7. Только затем разрешить силовой драйвер.

## Надежность обмена

Драйвер должен иметь:

- тайм-аут ответа;
- ограниченное число повторов;
- журнал отправленных команд и принятых байтов;
- проверку допустимого диапазона до отправки;
- блокировку недокументированных команд по умолчанию;
- восстановление полной конфигурации после сброса;
- аппаратный безопасный выход при ошибке.

## Электрические меры

Перед прямым подключением к ESP32, RP2040 или другому 3,3-вольтовому MCU измерьте напряжение покоя и амплитуду на `TXD` модуля.

При 5-вольтовом TXD применяйте:

- двунаправленный преобразователь уровней; либо
- резистивный делитель только для направления `TXD модуля -> RX MCU`.

Общая земля обязательна, если не применяется гальваническая развязка.
