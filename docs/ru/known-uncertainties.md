# Неопределенности и статус сведений

| Сведение | Статус | Примечание |
|---|---|---|
| Два независимых PWM-канала | заявлено продавцом | требуется проверка независимости при изменении параметров |
| Питание 5–30 В | заявлено продавцом | проверить нагрев и защиту |
| Micro-USB 5 В | заявлено продавцом | неясна развязка с основным входом |
| Диапазон 1 Гц–150 кГц | заявлено продавцом | верхний диапазон требует проверки протокола |
| Точность ±2% | заявлено продавцом | метод измерения не указан |
| Заполнение 1–100% | заявлено продавцом | 0% не подтверждено |
| Выход 5 Vp-p | заявлено продавцом | уровень может зависеть от питания/ревизии |
| Выходной ток менее 30 мА | заявлено продавцом | считать абсолютным максимумом нельзя |
| UART 9600 8N1 | документировано | электрические уровни не указаны |
| Установка параметров по UART | документировано | подтверждается командами `S1/S2`, `F/D` |
| Чтение параметров по UART | не документировано | TXD может использоваться только для подтверждения |
| Ответ `DOWN`/`FALL` | документировано | возможна ошибка перевода или вариация прошивки |
| Энергонезависимое сохранение | заявлено продавцом | проверить длительность и момент записи |

После каждого испытания обновляйте эту таблицу и прикладывайте исходные измерения.
