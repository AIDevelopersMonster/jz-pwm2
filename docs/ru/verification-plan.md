# План аппаратной проверки JZ-PWM2

Цель — отделить подтвержденные свойства конкретного экземпляра от текста карточки продавца.

## 1. Идентификация

- сфотографировать обе стороны платы;
- записать маркировку микроконтроллера и других ИС;
- измерить размеры и межосевые расстояния;
- зафиксировать вариант маркировки платы и дату покупки.

## 2. Питание

Проверить работу при 5, 12, 24 и 30 В на основном входе, а также при 5 В через Micro-USB.

Зафиксировать:

- потребляемый ток;
- нагрев;
- наличие обратного питания между входами;
- поведение при одновременном подключении двух источников;
- состояние выходов при включении и выключении.

Не подключать два источника одновременно до проверки схемы питания.

## 3. UART

Измерить осциллографом:

- напряжение покоя `TXD`;
- амплитуду логических уровней;
- полярность;
- фактическую скорость;
- наличие завершающих символов `CR` и/или `LF` в ответах.

Проверить команды:

- `S1F100T`;
- `S2F100T`;
- `S1F54.1T`;
- `S1D025T`;
- `S2D075T`;
- заведомо ошибочную команду.

Сохранить ответы в шестнадцатеричном и текстовом виде.

## 4. PWM

Для обоих каналов измерить:

- амплитуду;
- частоту;
- заполнение;
- джиттер;
- выходное сопротивление приблизительным нагрузочным методом;
- максимальный безопасный ток без заметного искажения.

Контрольные точки частоты: 1, 10, 100, 999 Гц; 1,0, 10,0, 54,1, 99,9 кГц; 100, 124 и 150 кГц.

Контрольные точки заполнения: 1, 10, 25, 50, 75, 99 и 100%.

## 5. Неопределенные функции

Отдельно проверить:

- принимает ли модуль `D000`;
- как выглядит физический выход при 100%;
- точный формат UART-команд для 100–150 кГц;
- существуют ли недокументированные команды чтения;
- сохраняются ли значения после отключения питания;
- может ли UART изменять параметры во время ручного режима;
- появляются ли кратковременные неверные импульсы при обновлении.

## 6. Критерий допуска

Модуль может применяться в прототипе после подтверждения уровней UART и отсутствия опасных импульсов при включении. Для ответственной силовой системы требуется внешний аппаратный `ENABLE` независимо от результатов теста.
