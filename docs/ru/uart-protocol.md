# UART-протокол JZ-PWM2

## 1. Параметры линии

| Параметр | Значение |
|---|---|
| Скорость | 9600 бод |
| Биты данных | 8 |
| Четность | нет |
| Стоп-биты | 1 |
| Управление потоком | нет |
| Представление команд | ASCII |

Интерфейс в исходной карточке товара назван `Serial communication`. Электрический стандарт не указан. До измерения нельзя считать доказанным, что уровни совместимы с 3,3 В.

## 2. Формат команд

Общая структура:

```text
S<канал><операция><значение>T
```

Где:

- `S1` — канал PWM1;
- `S2` — канал PWM2;
- `F` — установка частоты;
- `D` — установка коэффициента заполнения;
- `T` — признак конца команды.

## 3. Частота 1–999 Гц

```text
S1F100T
S2F999T
S1F001T
```

По описанию продавца значение кодируется тремя цифрами.

## 4. Частота 0,1–99,9 кГц

```text
S1F54.1T
S2F25.0T
```

В значении используется одна десятичная цифра в килогерцах.

## 5. Частота 100–150 кГц

На дисплее значения обозначаются записью с несколькими точками, например `1.2.4.` для 124 кГц. Формат UART-команды в исходной инструкции переведен неоднозначно и должен быть подтвержден испытанием.

До проверки программная библиотека репозитория намеренно не формирует команды выше 99,9 кГц автоматически.

## 6. Коэффициент заполнения

```text
S1D025T
S2D075T
S1D100T
```

Документированный диапазон: `001–100`. Поддержка `000` не подтверждена.

## 7. Ответы

В исходном описании указано:

```text
DOWN
```

при успешной установке и:

```text
FALL
```

при ошибке.

Возможна ошибка перевода вместо `DONE` и `FAIL`. Драйвер должен журналировать фактические байты ответа, а не молча подменять их предполагаемыми значениями.

## 8. Что не документировано

Не обнаружены команды для:

- чтения текущей частоты;
- чтения текущего заполнения;
- чтения версии прошивки;
- отключения канала отдельной командой;
- синхронного запуска каналов;
- задания фазового сдвига;
- адресации нескольких модулей на одной линии;
- контрольной суммы или номера транзакции.
